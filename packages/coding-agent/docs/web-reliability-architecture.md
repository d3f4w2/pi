# 网页读取可靠性架构

## 目标

让网络超时、取消、重定向和响应流错误只终止当前工具调用，不能导致 Pi 进程退出。

## 设计

- 全局最多 4 个网页请求；超过上限立即返回，不排长队。
- 同一轮中完全相同的 `web_fetch` 合并为一个请求。
- 用户取消后不再从 Brave 回退到 DuckDuckGo。
- Undici 的取消和流错误统一转换为简短错误。
- 响应流销毁前安装 error listener，清理错误不向事件循环泄漏。
- 保留现有 SSRF、重定向、内容类型、大小和超时限制。

## 性能

请求合并减少重复下载；并发上限保护连接池和内存。没有重试退避，因此失败不会拖慢整个代理任务。
