# 工具操作确认

Pi 会在工具真正执行前判断风险。普通操作不增加模型调用，也不占用额外上下文。

## 三种风险

- `read`：只读取，例如 `read`、`grep`、网页搜索。
- `write`：修改文件或会话数据，例如 `edit`、`write`。
- `exec`：运行命令或未知扩展工具，例如 `bash`。

没有声明风险的未知工具按 `exec` 处理。

## 三种模式

在交互界面按 `Shift+Tab` 可以依次切换：

```text
yolo → write → always-ask → yolo
```

修改会立即生效并保存，下次启动继续使用。思考等级在 `/model` 选择模型后设置。

在 `~/.pi/agent/settings.json` 中配置：

```json
{
  "tools": {
    "approvalMode": "yolo",
    "approval": {
      "bash": "prompt",
      "read": "allow",
      "untrusted_tool": "deny"
    }
  }
}
```

| 模式 | 自动执行 | 需要确认 |
|---|---|---|
| `always-ask` | 无 | 读取、修改、运行 |
| `write` | 读取 | 修改、运行 |
| `yolo`（默认） | 普通读取、修改、运行 | 明确危险操作 |

单个工具可设置为 `allow`、`prompt` 或 `deny`。`deny` 始终优先。

## 危险操作

以下操作即使在默认模式也会确认：

- `git reset --hard`、强制推送、强制清理；
- 删除根目录或用户目录；
- 关机、重启、格式化磁盘；
- 下载脚本后立即执行；
- 修改当前工作区外的文件。

确认时可以选择：

- 只允许本次；
- 当前会话允许参数完全相同的操作；
- 始终允许这个工具，写入白名单；
- 始终禁止这个工具，写入黑名单；
- 只拒绝本次。

白名单和黑名单保存在 `settings.json` 的 `tools.approval` 中。明确危险操作不会被普通白名单绕过。没有交互界面时，需要确认的操作会被拒绝，不会静默放行。

## 管理持久权限

输入 `/permissions` 可以查看和修改所有已注册工具：

- `↑/↓`：选择工具；
- `←/→`：切换“跟随模式、每次询问、始终允许、始终禁止”；
- `Enter`：保存到 `settings.json`；
- `Esc`：取消本次修改。

“跟随模式”表示删除该工具的单独规则，重新使用当前的便捷、标准或严格模式。也可以直接编辑 `tools.approval`，但通常不需要这样做。

## 查看状态

- `/tools` 显示每个工具的基础风险：`读`、`写`、`执行`。
- `/permissions` 管理每个工具的持久执行权限。
- `/doctor` 显示当前确认模式和工具熔断状态。
