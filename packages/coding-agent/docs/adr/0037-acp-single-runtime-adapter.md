# ADR 0037：ACP 只作为单一运行时的传输适配层

- 状态：Accepted
- 日期：2026-08-10

## 问题

单独为编辑器实现一套 Agent 会产生两套会话、工具状态和权限判断。同一任务在 TUI 与编辑器中的结果会不一致。

## 决策

ACP 使用官方 TypeScript SDK解析协议，但所有请求交给现有 `AgentSessionRuntime`。会话历史、模型、工具、审批、取消和用量事件只保留一份。协议 NDJSON 直接写 stdout，其他输出继续受 output guard 管理。

编辑器传入的 MCP 服务只存在于对应会话。客户端缺少可选文件或终端能力时继续使用 pi-go 本地工具，并保留相同安全边界。

## 结果

TUI、RPC 和 ACP 的行为一致，新增协议不会扩大核心状态面。代价是尚未声明的 ACP 可选能力不会自动伪装为已支持。
