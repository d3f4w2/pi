# ADR 0045: ACP 客户端能力路由

## 状态

Accepted

## 问题

ACP 编辑器可能提供自己的文件系统和终端。始终本地执行会绕过编辑器的虚拟工作区；始终远端执行又会让能力不完整的客户端无法使用。例如只声明读取能力的编辑器不能安全承接 `edit`。

## 决策

初始化时记录客户端声明的能力，并通过现有工具操作接口逐项覆盖：读取对应 `read`，写入对应 `write`，读取加写入同时存在才对应 `edit`，终端对应 `bash`。没有声明的能力继续使用本地实现。

审批仍由 Pi 在调用操作前完成。客户端操作一旦选中，失败不会退回本地重试；否则写入或命令可能执行两次。能力覆盖保存在 `AgentSession` 的基础工具定义中，并在资源重新加载后重建。

## 结果

ACP 能处理编辑器虚拟文件和终端，同时保持 TUI/RPC 的本地行为。客户端声明错误会显式失败，而不是产生位置不明的副作用。
