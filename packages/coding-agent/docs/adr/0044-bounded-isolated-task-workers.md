# ADR 0044: 有界隔离任务 worker

## 状态

Accepted

## 问题

单个 Agent 顺序执行独立调查会增加总耗时；直接让多个 Agent 共用工作区又会覆盖并发窗口的修改。例如两个编码任务同时编辑 `src/index.ts`，即使各自逻辑正确，后写入者仍可能丢失先写入者的内容。

## 决策

提供会话级 `task` 工具，最多并行三个 worker。每个 worker：

- 在系统临时目录创建不跟随符号链接的项目快照。
- 排除 `.git`、依赖、构建输出和评测产物，并限制文件数与总字节数。
- 使用父会话的模型和思考等级，但使用独立内存会话。
- `research` 只启用读工具；`coding` 启用读写和 Bash；两者都不启用 `task`。
- 有硬超时、显式取消、32 KiB 模型输出上限和结构化 token/工具统计。
- 不自动把修改合并回父工作区。

## 结果

独立工作可以并行，父工作区保持单写者。代价是快照不复制 `node_modules`，因此某些编码 worker 只能完成源文件修改，依赖完整安装的验收仍由父 Agent 执行。
