# ADR 0039：MCP 采用懒连接能力桥

- 状态：Accepted
- 日期：2026-08-10

## 问题

如果每次启动都同步连接全部 MCP 服务，一个离线服务就会拖慢整个 Agent；如果把远端工具直接执行，又会绕过本地审批和输出限制。

## 决策

MCP 配置先转换为本地工具描述。安全缓存立即注册，真实服务在会话开始后后台连接；远端工具仍经过本地 read/exec 审批、取消和结果上限。stdio 使用无 shell 的参数数组启动，HTTP/SSE 复用官方客户端传输。资源交给统一 `read`，提示词只通过显式 `/mcp` 操作读取。

失败只熔断对应服务。配置、缓存指纹和状态不保存密钥值。会话结束关闭客户端和子进程。

## 结果

普通启动不被外部服务阻塞，MCP 也不能成为绕过工具策略的旁路。代价是首次调用冷服务可能多一次连接延迟。
