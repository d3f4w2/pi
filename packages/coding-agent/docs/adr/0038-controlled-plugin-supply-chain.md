# ADR 0038：插件安装、信任和运行分离

- 状态：Accepted
- 日期：2026-08-10

## 问题

插件是当前用户权限下运行的代码。仅凭包名安装并立即加载，无法回答“运行了哪些文件、用户批准的是哪个版本、更新失败后如何恢复”。

## 决策

受控插件必须提供版本化 `pi-plugin.json`，逐文件声明扩展、Skill、MCP 和资源，并绑定 SHA-256。加载器拒绝路径越界、符号链接、生命周期脚本、版本不兼容和哈希变化。

下载阶段统一使用 `--ignore-scripts`。校验后展示能力和指纹，用户确认才把指纹写入注册表。更新先原子移走旧目录，再安装和复核；失败或拒绝恢复旧目录，成功后保留一个版本供反向交换回滚。

## 结果

插件从“配置里出现就运行”变为可审计、可停用、变更后重新确认、可回滚的供应链。扩展代码仍是同进程受信代码，清单不是沙箱，这一点必须在启用界面明确说明。
