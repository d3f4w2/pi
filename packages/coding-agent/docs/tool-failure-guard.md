# 工具重复失败保护

当代理使用完全相同的工具和参数，并连续得到完全相同的错误时，Pi 会阻止它无限重复。

默认规则：

1. 第一次调用正常执行。
2. 第二次相同调用仍然执行，给瞬时问题一次恢复机会。
3. 如果两次错误也相同，第三次调用不会执行底层工具。
4. 代理会收到明确提示：修改参数、换工具，或者说明当前阻塞原因。
5. 如果代理无视提示，再次重复同一个被阻止的调用，当前自动运行会结束，避免继续消耗 Token。

以下情况会重新允许调用：

- 参数发生变化
- 返回了不同错误
- 任意工具有一次调用成功
- 用户发送新消息
- 开始新的代理运行

中止和取消不计入失败次数。被阻止的调用仍然生成标准工具结果，因此不会破坏模型接口的调用顺序。

## 配置

```json
{
  "toolFailureGuard": {
    "enabled": true,
    "repeatLimit": 2
  }
}
```

通常不需要修改默认值。关闭后，Pi 不再提供这层通用保护，但各个工具自己的错误处理仍然有效。
