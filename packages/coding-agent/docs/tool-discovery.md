# 按需加载工具

Pi 会把低频工具先收起来，需要时再加载。这样模型每一轮要阅读的工具说明更少，通常更省 token，也更不容易选错工具。

你不需要手动调用它。代理在缺少某种能力时，可以调用：

```text
tool_search("检查代码结构")
```

它会加载最相关的工具，最多 2 个，下一轮就能使用。

## `/tools` 中的“开”是什么意思

```text
[开] 允许代理使用
[关] 禁止代理使用
```

`[开]` 不代表工具每一轮都显示给模型。低频工具可能等到需要时才临时加载。你的开关选择仍会保存到：

```text
~/.pi/agent/tool-preferences.json
```

## 想恢复旧行为

在 `/tools` 中关闭 `tool_search`。Pi 会停止按需隐藏，所有处于 `[开]` 状态的工具都会直接可用。

## 重要边界

- `tool_search` 只加载工具，不会直接执行工具。
- 一次最多加载 2 个工具，再次搜索会替换上一次结果。
- 搜索在本机完成，不联网、不额外调用模型。
- 搜索失败不会反复重试，也不会阻塞当前任务。
