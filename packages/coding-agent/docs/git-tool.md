# Git 版本管理

Pi 内置一个结构化 `git` 工具和一个给用户操作的 `/git` 界面。两者使用同一套安全规则。

## 使用方式

在 Pi 中输入：

```text
/git
```

界面支持：

- `↑/↓`：选择文件。
- `→`：暂存当前文件。
- `←`：取消暂存当前文件。
- `Enter`：查看当前文件的 Diff。
- `Esc`：返回。

主菜单还可以提交暂存内容、查看提交历史和推送当前分支。提交和推送前都会再次确认。

代理也可以调用同一个 `git` 工具，支持：

- `overview`：查看分支和变更摘要。
- `diff`：查看一个文件的变更。
- `log`：查看最近提交。
- `stage` / `unstage`：按明确文件列表修改暂存区。
- `commit`：提交当前暂存区。
- `push`：推送到远程仓库。

## 安全边界

- 直接运行本机 Git，不经过 Bash、WSL 或 PowerShell。
- 不接受任意 Git 参数。
- 不提供强制推送、硬重置、删除分支等危险操作。
- 暂存只操作明确列出的文件。
- 提交前会确认声明的文件与实际暂存文件完全一致。
- 推送始终需要用户确认。
- 大文件、超长输出和超时操作会被停止。

## 安装要求

只需要本机已经安装 Git，并且 `git` 命令可用，不需要额外配置。
