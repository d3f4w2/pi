# ast_grep 代码结构搜索

`ast_grep` 按代码的语法结构搜索，不按普通文字搜索。它能分清真正执行的代码、注释和字符串。

## 什么时候使用

- 找所有 `console.log(...)` 调用
- 找所有特定形状的函数、条件或组件
- 找写法不同但结构相同的代码

已知准确文字时用 `grep`；查定义、引用、类型和错误时用 `lsp`；按功能意思探索未知位置时用 `code_search`。

## 使用方法

在 `/tools` 中用右方向键开启 `ast_grep`。选择会自动保存。

示例：

```text
ast_grep pattern="console.log($$$ARGS)" path="packages"
```

- `$NAME`：匹配一个语法节点
- `$$$ARGS`：匹配零个或多个语法节点
- `language`：可选，默认 `auto`，一次自动处理所有支持的文件类型
- `path`：可选，限制到一个文件或文件夹
- `max_results`：可选，默认 100；明确需要全部结果时使用 1000

目前内置支持 JavaScript、TypeScript、TSX、HTML 和 CSS，不需要另外安装或登录。

结果不超过 20 条时会显示代码片段。结果较多时自动按文件压缩，只显示行号和列号，例如：

```text
找到 25 处，分布在 2 个文件：
src/a.ts: 10:2, 18:4, 27:1
src/b.tsx: 6:12, 20:3
```

## 限制

- 只搜索，不修改代码。
- 最多扫描 5000 个文件，超过后会要求缩小 `path`。
- 单文件超过 1 MB 会跳过。
- 搜索超过 15 秒会停止，并提示改用 `grep`。
- 位置列表最多输出约 30000 个字符，超过后会要求缩小 `path`。
- 默认跳过 `.git`、`node_modules`、`dist`、`build`、`coverage`、`.next`、`out` 和 `vendor`。
