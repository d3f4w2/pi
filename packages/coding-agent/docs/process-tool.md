# 后台进程工具

`process` 用于开发服务器、文件监听器和测试观察模式等不会主动退出的程序。

## 使用方式

可以直接告诉 Pi：

```text
启动 npm run dev，并在后台观察日志
```

也可以输入：

```text
/process
```

界面支持启动、查看、停止、重启和读取日志。

代理工具支持：

- `start`：直接启动可执行文件和参数数组。
- `status`：查看托管进程状态。
- `logs`：按游标只读取新增日志。
- `restart`：重启指定托管进程。
- `stop`：停止指定托管进程。

## 行为边界

- 不经过 Bash、WSL 或 PowerShell，也不解释 `&&`、管道等 Shell 语法。
- 只允许项目内工作目录。
- 只停止当前 Pi 会话创建的进程。
- 最多同时运行八个托管进程。
- 日志有大小上限，返回 `next_cursor` 后应使用它读取新增内容。
- 退出 Pi 时自动停止全部托管进程。

设计决策见 [ADR-0015](adr/0015-session-scoped-background-processes.md)。
