# 持久 Python/Bun 运行环境架构

## 目标

让代理在同一项目中连续执行小段 Python 或 JavaScript，变量和导入在多次调用之间保留，避免反复启动解释器。

## 设计

`eval` 工具提供三种操作：

- `execute`：运行代码并返回输出和最后一个表达式的值。
- `reset`：结束指定语言的进程，清空状态。
- `status`：查看哪些运行环境正在运行。

每个项目、每种语言最多一个长驻进程。第一次调用时按需启动，后续调用复用。会话关闭时结束全部子进程。

## 安全边界

- 工具属于 `exec` 审批等级。
- 使用参数数组启动进程，不经过 shell。
- 默认移除名称包含 key、token、secret、password、credential、auth 的环境变量。
- 单次执行默认 10 秒，最长 60 秒；超时后杀掉进程，下次重新启动。
- 单次输出最多 32 KB。
- 代码仍能访问当前用户可读的文件，因此信任边界与终端执行相同，不是安全沙箱。

## 失败处理

Python 不可用时提示安装 Python；Bun 不可用时提示安装 Bun。进程退出、协议损坏或超时都会立即清理，不自动循环重试。
