# 代理内部一键专项测评实现计划

## 目标

用户在 pi-go 内只输入 `/evals`，再从菜单选择最近或历史回归 case，无需记忆子命令或判断外部测试命令。

## 步骤

1. 增加独立的回归 case 运行器。
   - 输出：文件验证、框架识别、直接进程参数和有界结果。
   - 测试：覆盖 node:test、Vitest、pytest、Go、哈希变化和未知框架。
2. 接入 `/evals` 评测中心。
	- 输出：最近案例、历史案例、报告和高级功能四个入口；内部仍支持子命令。
	- 测试：命令只调用目标 case，并正确传递工作目录和取消信号。
3. 更新 case 创建结果和文档。
	- 输出：生成后直接提示打开 `/evals`。
	- 测试：中英文提示都只暴露一个普通用户入口。
4. 验证当前真实 case。
   - 输出：在内部运行器路径下得到明确结果。
   - 测试：专项测试与 `npm run check` 通过。

## 限制

- 不自动执行测试。
- 不隐式运行整个仓库。
- 不安装缺失的测试框架。
- 不尝试修复失败测试。
